Execute a small, decision-light plan or request through context-isolated subagent tasks that share the same writable workspace, so the main conversation keeps only compact results instead of file contents. A persistent run ledger under `.xsk/runs/` records every task and its acceptance state, so a mid-run context compression loses nothing that matters.

It fits tasks that are simple to decide but heavy to execute: the work reads and writes far more content than the task description itself (several files, several steps). Its evidence bookkeeping carries a real fixed cost, since a Git baseline, path-state fingerprints, and anchored checkpoints are all established before the first task runs, so the work has to be large enough to earn that overhead. Anything small enough to inspect directly, including a one-file tweak or a single command, is cheaper done inline.
